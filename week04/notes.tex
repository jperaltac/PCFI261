\begin{frame}[fragile]
\frametitle{¿Qué es dinámica molecular?}

En el método de Dinámica Molecular se simulan las \textbf{trayectorias} en el tiempo 
de átomos individuales, de acuerdo a las leyes de la \textbf{mecánica clásica}, con el fin 
de calcular \textbf{propiedades macroscópicas} en acuerdo con la Termodinámica.

\vspace{15pt}
Actualmente es posible simular rutinariamente sistemas del orden de \textbf{millones de átomos} por escalas
de tiempo de \textbf{nanosegundos}. 

\end{frame}

\begin{frame}[fragile]
\frametitle{Alcance de la Dinámica Molecular}

¿Qué podemos calcular con Dinámica Molecular? Entre otras cosas,

\begin{itemize}
\item Propiedades estructurales (estructura cristalina, patrones de difracción)
\item Propiedades mecánicas (módulo de compresión, constantes elásticas)
\item Propiedades termodinámicas (temperatura, presión, puntos de fusión, energías libres, diagramas de fase)
\item Propiedades de transporte (difusión, conductividad térmica)
\end{itemize}

Además, tenemos acceso a las posiciones y velocidades de cada átomo en cada momento: podemos visualizar fenómenos colectivos!

\end{frame}

\begin{frame}[fragile]
\frametitle{Integración de las ecuaciones de movimiento}

Para el método de dinámica molecular, integramos las trayectorias según la segunda ley de Newton,

\begin{equation}
m_i \bm{a}_i(t) = \bm{F}_i(t)
\end{equation}
%
donde $\bm{a}_i = \ddot{\bm{x}_i}$ es la aceleración de la $i$-ésima partícula y $\bm{F}_i$ es la fuerza
sobre ella. Usualmente, $\bm{F}_i(t) = \bm{F}_i(\bm{x}_1(t), \ldots, \bm{x}_N(t))$.

\vspace{15pt}
Las fuerzas sobre las partículas incluyen tanto fuerzas externas al sistema como interacciones (repulsivas y atractivas) 
con otras partículas.

\begin{block}{}
Para resolver numéricamente la segunda ley de Newton debemos avanzar a las partículas 
en pasos discretos de tamaño $\Delta t$ (típicamente del orden de 1 fs).
\end{block}

\end{frame}

\begin{frame}[fragile]
\frametitle{Flujo de un programa de dinámica molecular básico}

\begin{enumerate}
\item Inicializar las posiciones y velocidades.
\item Calcular las fuerzas sobre cada partícula, tanto de interacción con sus ``vecinos'' como fuerzas externas.
\item Avanzar las posiciones y velocidades utilizando algún método de integración.
\item Calcular propiedades macroscópicas (energías, temperatura, presión, etc.)
\item Volver a (2).
\end{enumerate}

\end{frame}

\frametitle{Potenciales interatómicos}
Un modelo muy sencillo pero que captura mucha información acerca de las interacciones moleculares 
es el potencial de Lennard--Jones,

\begin{columns}
\begin{column}{6.5cm}
\begin{center}
\includegraphics[width=6.0cm]{argonLJ.png}
\end{center}
\end{column}
\begin{column}{5.0cm}
\begin{eqnarray}
U_i = \sum_{j \neq i } U(r_{ij}) \\
U(r_{ij}) = 4 \epsilon \left[\left(\frac{\sigma}{r_{ij}}\right)^{12} - \left(\frac{\sigma}{r_{ij}}\right) ^{6}\right]
\end{eqnarray}
\end{column}
\end{columns}

\begin{center}
Para arg\'on, $\sigma$ = 3.41 \AA ~and $\epsilon$ = 119.8 K$\cdot$ $k_B$
\end{center}

\begin{frame}[fragile]
\frametitle{El algoritmo de Euler}

Existen muchos algoritmos para avanzar las posiciones y velocidades en el tiempo. El primero, de interés más bien histórico, es 
el algoritmo de Euler, el cual consiste en usar directamente la expansión de Taylor a segundo orden en $\Delta t$ para las
posiciones,

\begin{eqnarray}
\bm{x}(t+\Delta t) \approx \bm{x}(t) + \bm{v}(t)\Delta t + \frac{1}{2}\bm{a}(t)(\Delta t)^2, \nonumber \\
\bm{v}(t+\Delta t) \approx \bm{v}(t) + \bm{a}(t)\Delta t.
\end{eqnarray}
%
donde $\bm{v}=\dot{\bm{x}}$ es la velocidad de la partícula. Este método tiene un error del orden $(\Delta t)^3$ en las posiciones 
y de orden $(\Delta t)^2$ en las velocidades.

\end{frame}

%
%
%
\begin{frame}[fragile]
\frametitle{El algoritmo de Verlet}

Otro algoritmo, más usado en la práctica, es el algoritmo de Verlet. La discretización escogida por Verlet es

\begin{equation}
\bm{x}(t+\Delta t) \approx 2\bm{x}(t) - \bm{x}(t-\Delta t) + \bm{a}(t)(\Delta t)^2
\end{equation}
%
donde el primer paso se da según el algoritmo de Euler,

\begin{equation}
\bm{x}(\Delta t) \approx \bm{x}(0) + \bm{v}(0)\Delta t + \frac{1}{2}\bm{a}(0)(\Delta t)^2.
\end{equation}

Este método tiene un error del orden $(\Delta t)^4$ en las posiciones. Las velocidades no se usan 
explícitamente, excepto en el primer paso. Si se desea calcularlas, es posible usar

\begin{equation}
\bm{v}(t) \approx \frac{\bm{x}(t+\Delta t)-\bm{x}(t-\Delta t)}{2\Delta t}
\end{equation}
%
con error de orden $(\Delta t)^2$.

\end{frame}

%
%
%
\begin{frame}[fragile]
\frametitle{El algoritmo ``velocity Verlet''}

Una variante del algoritmo de Verlet que sí incorpora las velocidades es

\begin{eqnarray}
\bm{x}(t+\Delta t) \approx \bm{x}(t) + \bm{v}(t)\Delta t + \frac{1}{2}\bm{a}(t)(\Delta t)^2, \nonumber \\
\bm{v}(t+\Delta t) \approx \bm{v}(t) + \frac{ \bm{a}(t) + \bm{a}(t+\Delta t)}{2}\Delta t.
\end{eqnarray}

Este método tiene un error del orden $(\Delta t)^4$ en posiciones y de orden $(\Delta t)^2$ en las velocidades.

\end{frame}

\begin{frame}[fragile]
\frametitle{Actividades}

Actividades a realizar:

\begin{enumerate}
\item[(a)] Escriba un programa que simule un ``billar'' bidimensional de 2 partículas que sólo chocan contra 
las paredes (no existe aceleración). Para esto use el algoritmo de Euler.
\item[(b)] Modifique su programa para incorporar una aceleración constante hacia abajo. Resuelva las ecuaciones de movimiento
con el algoritmo \emph{velocity Verlet}.
\item[(c)] Modifique el programa anterior para hacer que al chocar las dos partículas (distancia menor a 1\% del largo de la
caja) la dirección de sus velocidades resulte modificada al azar. Esto simula fuerzas repulsivas de contacto.
\end{enumerate}
