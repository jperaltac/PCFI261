\section{Clase 1}

\begin{frame}[plain]

{\Large Redes densas como emuladores de modelos fisicos}
\vfill

\begin{frame}{Objetivos de la Clase 1}
\begin{itemize}
    \item Construir un laboratorio simulado: muchas curvas de osciladores amortiguados con parametros distintos.
    \item Entrenar una red densa que funcione como \textbf{sustituto rapido} del modelo fisico.
    \item Usar el emulador con parametros nuevos, como hariamos con un caso nuevo en Pima Indians.
    \item Discutir para que sirve: exploracion de parametros, ajuste a datos experimentales y simuladores caros.
\end{itemize}
\end{frame}

\begin{frame}{Para que serviria este ``cerebro''?}
\begin{columns}[T,onlytextwidth]
\column{0.48\textwidth}
\begin{block}{Analogía con Pima}
En Pima, entrenamos con muchos pacientes y luego evaluamos a una persona nueva para estimar riesgo.
\end{block}
\begin{itemize}
    \item Entrada nueva: edad, glucosa, IMC, etc.
    \item Salida: probabilidad de diabetes.
\end{itemize}

\column{0.48\textwidth}
\begin{block}{Analogía fisica}
Aqui entrenamos con muchas curvas y luego evaluamos un sistema nuevo para estimar su respuesta.
\end{block}
\begin{itemize}
    \item Entrada nueva: $A,\gamma,\omega,\phi$ y tiempos.
    \item Salida: curva esperada $\hat{x}(t)$.
\end{itemize}
\end{columns}
\end{frame}

\begin{frame}{Uso experimental: del dato al parametro}
\begin{itemize}
    \item Supongamos que medimos una vibracion real: tenemos puntos ruidosos $x_{\rm obs}(t)$.
    \item Probamos muchos parametros posibles: $\gamma$, $\omega$, amplitud y fase.
    \item El emulador predice rapidamente la curva para cada combinacion.
    \item Elegimos los parametros cuya curva se parece mas a la medicion.
\end{itemize}
\begin{alertblock}{Idea central}
La red no reemplaza la fisica. Sirve como una version rapida y diferenciable del modelo, util cuando simular muchas veces seria lento.
\end{alertblock}
\end{frame}

\begin{frame}{Aplicacion fisica: oscilador amortiguado}
\begin{columns}[T,onlytextwidth]
\column{0.52\textwidth}
\justifying
Un oscilador amortiguado simple puede escribirse, en una version docente, como
\[
 x(t)=A\,e^{-\gamma t}\cos(\omega t+\phi).
\]
En un laboratorio real, cada curva podria venir de una medicion con ruido. Aqui controlamos el experimento: elegimos parametros, calculamos la curva y agregamos ruido pequeno.

\begin{block}{Lectura fisica}
El \textbf{emulador} recibe tiempo y parametros, y devuelve una posicion aproximada. Sirve cuando queremos consultar el modelo muchas veces.
\end{block}

\begin{frame}{Que significa que el emulador funcione}
\begin{itemize}
    \item Debe reproducir amplitud, fase y decaimiento en curvas no vistas.
    \item El error no debe concentrarse solo en una zona temporal o en un rango de parametros.
    \item Si extrapolamos fuera del rango entrenado, el modelo puede fallar aunque entregue numeros plausibles.
\end{itemize}

\begin{frame}{CPU versus GPU: cuando empieza a importar}
\begin{columns}[T,onlytextwidth]
\column{0.52\textwidth}
\begin{itemize}
    \item Para miles de ejemplos, una CPU puede bastar.
    \item La GPU ayuda cuando hay muchas operaciones matriciales similares.
    \item Aumentar el dataset sintetico permite medir el cambio sin buscar archivos externos.
    \item La GPU acelera entrenamiento, pero no arregla mala validacion ni mala pregunta fisica.

\begin{frame}{Objetivos de la Clase 2}

\begin{frame}{Aplicacion astronomica: una caida de brillo}
\begin{columns}[T,onlytextwidth]
\column{0.52\textwidth}
\justifying
Cuando un planeta pasa frente a su estrella, el brillo observado puede bajar levemente durante un intervalo corto. Podemos imaginar cada curva como una serie de mediciones de flujo tomadas por un instrumento. En esta clase generamos curvas sinteticas con ruido y entrenamos una red densa para distinguir:
\begin{itemize}
    \item estrella sin transito;
    \item estrella con una senal de transito simple.
\end{itemize}

\begin{alertblock}{Limite del modelo}
No haremos astronomia de precision. Buscamos una experiencia docente: senal, ruido, clasificacion y validacion.
\end{alertblock}

\column{0.44\textwidth}
\centering
\resizebox{0.96\linewidth}{!}{\input{Figuras/exoplanet_transit.tex}}
\end{columns}
\end{frame}

\begin{frame}{Por que todavia no usamos CNN}
\begin{itemize}
    \item Una curva de luz discretizada puede verse como un vector: $[f_1,f_2,\ldots,f_N]$.
    \item Una red densa puede aprender combinaciones globales de esos puntos.
    \item Las CNN seran utiles mas adelante para explotar estructura local, ventanas y patrones desplazados.
    \item Aqui mantenemos el foco en redes densas, validacion y GPU.
\end{itemize}
\end{frame}
